# samples（テスト用データ）

**ここにあるデータはすべて架空です。** 実在の患者・医師・医療機関とは関係ありません。
文字コードは実物と同じ **Shift_JIS（CP932）・CRLF** です（エディタで開くと文字化けすることがあります）。

## original_anon/ — 実ファイルの匿名化版

M3デジカルが実際に出力したCSV・PDF（1か月分）を、**行の構成（行数・患者ごとの行数・同じ日に複数指摘・保険やチェック内容のパターン）はそのままに**、次の値を架空のものに置き換えました。

| 項目 | 置き換え方 |
|---|---|
| 患者番号 | 同じ桁数のランダムな番号 |
| 患者氏名 | 架空の名前（全角英字の外国人名は `ＳＡＭＰＬＥ　ＪＯＨＮ　ＤＯＥ`） |
| カルテ内部ID（URL内） | ランダムな7桁 |
| 医師 | `00001:見本　太郎` |
| 診療年月・診察日 | 2025年12月に変更。日付は患者ごとにランダム（同じ日の行はまとまったまま） |
| 出力日時 | 2026/01/08 09:47 |
| 公費の負担者番号 | `21999999` |
| 診療科・保険・薬剤名・チェック区分 | 実物のまま（個人を特定する情報ではないため） |

- `要確認レセプト一覧_20260108_0947.csv` … 55行 / 40人
- `要確認レセプト一覧_20260108.pdf` … 上のCSVから `tools/make_pdf_from_csv.py` で作ったPDF。実物と同じレイアウト・リンク注釈・テキスト抽出の癖を再現（SPEC 2.2）。フォントだけ実物と違う

ファイル名は実物と同じ形式（`要確認レセプト一覧_YYYYMMDD_HHMM.csv` / `要確認レセプト一覧_YYYYMMDD.pdf`）です。

## zip/ — パスワード付き ZIP のテスト用

`original_anon/` の CSV を `tools/make_test_zips.py` で ZIP にしたもの。パスワードはすべて `test-pass`。

| ファイル | 内容 |
|---|---|
| `zipcrypto_sjis.zip` | 従来の ZIP 暗号（ZipCrypto）。中のファイル名は Shift_JIS |
| `aes256_utf8.zip` | AES-256。中のファイル名は UTF-8 |
| `plain.zip` | パスワードなし |
